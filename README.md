# 💜 BTS Music Player (방탄소년단)

A modern, glassmorphic, uninterrupted web music player dedicated to BTS (Bangtan Sonyeondan) and ARMY worldwide. Stream official BTS hits, albums, solos, and YouTube playlists with real-time listening indicators and full mobile/desktop responsiveness.

![BTS Music Player Preview](/public/bg.png)

---

## ✨ Features

- 🎵 **Full BTS Hit Catalog**: Instant playback for Dynamite, Butter, Boy With Luv, Spring Day, Blood Sweat & Tears, Fake Love, Run BTS, Seven, and more.
- 🔍 **Universal Search & Song Switcher**: Search any BTS track, paste any YouTube video/playlist link, or pick from instant quick-tags.
- 🎛️ **Full Playback Controls**: Play, Pause, Next, Previous, Volume Slider with Mute toggle, Track Scrubber, and Shuffle/Loop modes.
- 📱 **Cross-Platform Responsive**: Custom-tailored layouts for Android smartphones, tablets, laptops, and wide desktop screens.
- 🔔 **MediaSession API Integration**: Control music from Android notification shades, lock screens, and Bluetooth devices, or using keyboard media keys on PC & Mac.
- 👥 **Real-Time Live Listeners**: Live synchronized presence counter showing active listeners globally and across tabs.
- 💎 **Glassmorphism Aesthetic**: Dark-mode frosted glass, vinyl spin animations, and ambient glow.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
| :--- | :--- |
| <kbd>Space</kbd> or <kbd>K</kbd> | Play / Pause |
| <kbd>/</kbd> or <kbd>Ctrl</kbd> + <kbd>K</kbd> | Focus Search Bar |
| <kbd>→</kbd> / <kbd>←</kbd> | Seek Forward / Backward 5s (<kbd>Shift</kbd> for 10s) |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Volume Up / Down |
| <kbd>M</kbd> | Mute / Unmute |
| <kbd>N</kbd> | Next Track |
| <kbd>P</kbd> | Previous Track |
| <kbd>S</kbd> | Toggle Shuffle |
| <kbd>L</kbd> | Toggle Loop |

## 🛠️ Tech Stack

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/) + [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/) + Custom Glassmorphic CSS
- **Audio Engine**: [YouTube IFrame Player API](https://developers.google.com/youtube/iframe_api_reference)
- **Language**: TypeScript

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/PixelPerfectcodes/bts-music-player.git
cd bts-music-player
```

### 2. Install dependencies
```bash
npm install
# or
bun install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```
